A tutorial on how to create custom commands for the command palette.

## Usage

`npx @wordpress/create-block custom-commands --template @block-developer-cookbook/custom-commands`

## Variants

- `start` - scaffolds starting files for the tutorial
- `completed` - scaffolds the completed files for the tutorial

## Tutorial

The tutorial can be found in the main README.md file of the generated plugin or at [https://blockdevelopercookbook.com/recipes/custom-commands/](https://blockdevelopercookbook.com/recipes/custom-commands/)
