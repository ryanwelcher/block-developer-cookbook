# Dark Light Mode Block Template

This template provides a tutorial on how to create an interactive block that allows users to toggle between dark and light color schemes.

## Usage

```bash
npx @wordpress/create-block dark-light-mode --template @block-developer-cookbook/dark-light-mode
```

## Variants

- `start` - scaffolds starting files for the tutorial
- `completed` - scaffolds the completed files for the tutorial

## Tutorial

The tutorial can be found in the main README.md file of the generated plugin or at [https://blockdevelopercookbook.com/recipes/creating-a-dark-light-mode-block/](https://blockdevelopercookbook.com/recipes/creating-a-dark-light-mode-block/)
