This template provides a tutorial on how to use custom block bindings to bind the post excerpt to a block.

## Usage

`npx @wordpress/create-block bound-excerpt --template @block-developer-cookbook/bound-excerpt`

## Variants

- `start` - scaffolds starting files for the tutorial
- `completed` - scaffolds the completed files for the tutorial

## Tutorial

The tutorial can be found in the main README.md file of the generated plugin or at [https://blockdevelopercookbook.com/recipes/block-binding-variation/](https://blockdevelopercookbook.com/recipes/block-binding-variation/)
