This template provides a tutorial on how to connect a paragraph block to the post except using the Block Bindings API.

## Usage

`npx @wordpress/create-block example-plugin --template @block-developer-cookbook/connected-excerpt

## Variants

-   `start` - scaffolds starting files for the tutorial
-   `completed` - scaffolds the completed files for the tutorial

## Tutorial

The tutorial can be found in the main README.md file of the generated plugin or at [https://blockdevelopercookbook.com/recipes/connected-excerpt/](https://blockdevelopercookbook.com/recipes/connected-excerpt/)
