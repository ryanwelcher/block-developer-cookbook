This template provides a tutorial to create a meme generator block.

## Usage

`npx @wordpress/create-block meme-generator --template @block-developer-cookbook/meme-generator`

## Variants

- `start` - starting files
- `completed` - final files

## Tutorial

The tutorial can be found in the main README.md file of the generated plugin or at [https://blockdevelopercookbook.com/recipes/meme-generator/](https://blockdevelopercookbook.com/recipes/meme-generator/)
