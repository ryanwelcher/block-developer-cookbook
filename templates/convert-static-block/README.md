A tutorial on how to convert a static block into a dynamic one.

## Usage

`npx @wordpress/create-block convert-static-block --template @block-developer-cookbook/convert-static-block

## Variants

- `start` - scaffolds starting files for the tutorial
- `completed` - scaffolds the completed files for the tutorial

## Tutorial

The tutorial can be found in the main README.md file of the generated plugin or at [https://blockdevelopercookbook.com/recipes/converting-to-a-dynamic-block](https://blockdevelopercookbook.com/recipes/converting-to-a-dynamic-block/)
